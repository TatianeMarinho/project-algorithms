🧠 Algorithms (Python)

Este repositório contém a implementação de diversos algoritmos clássicos para resolver problemas de otimização e busca. O foco principal foi entender e aplicar conceitos de Complexidade de Algoritmos (Big O Notation) e estratégias de resolução como Recursividade e Iteratividade.

🚀 O que foi desenvolvido:

Análise de Complexidade: Identificação do melhor e pior caso de execução (Tempo e Espaço).

Algoritmos de Busca e Ordenação: Implementações otimizadas para manipulação de grandes conjuntos de dados.

Recursividade vs Iteratividade: Resolução de problemas complexos (como o desafio do Palíndromo ou Encriptação) utilizando diferentes abordagens para comparar performance.

Lógica de Strings: Manipulação avançada de cadeias de caracteres.

🧰 Tecnologias utilizadas

Python 3: Pela sua legibilidade e poder de processamento.

Pytest: Para garantir a integridade dos algoritmos em diferentes cenários de teste.

Big O Notation: Como métrica de qualidade do código.
